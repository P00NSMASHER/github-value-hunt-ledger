## Component promotion rule
Promote here only when source/test evidence is stronger than README claims and the component closes a difficult cross-stack gap or changes a CAP/OPP/EXP. Commodity infrastructure stays lane-local. A strong component does not enter MASTER unless it adds unique positive-training DNA not already represented by a stronger leader.
