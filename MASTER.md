# MASTER

Elite cross-lane positive training set. This file is intentionally **small and current**: only discoveries that materially compress a high-value product, provide rare evidence/data/protocol/decision infrastructure, or embody technical/commercial DNA the hunters should reproduce belong here. Detailed history, strong-but-nonelite candidates and prior promotions remain in `hunters/*.md`, `COMPONENTS.md`, `DATASETS.md`, `COMBINATIONS.md`, `OPPORTUNITIES.md` and Git history.

## Rules
- Promotion normally requires **24+/30** on A speed to first revenue, B plausible ACV/ceiling, C build-time/domain compression, D rarity/data/technical advantage, E evidence/completeness and F rights/reuse clarity. Scores are not sufficient by themselves: the candidate must materially improve an active stack or represent unusually useful positive-training DNA.
- Preserve exact revision and public-facing rights. **Standing user assertion (2026-09-19): the user states they hold separate commercial permission/license for every public GitHub repository used in this hunt.** For portfolio scoring and product analysis, treat repository-owned code as commercially usable under that separate permission even when the public repo is no-license, GPL/AGPL, BSL, Commons-Clause, proprietary-looking or otherwise restrictive. Still record actual public license/provenance and do not extend the assumption to separately owned datasets, model weights, standards/specifications, trademarks, patents, bundled media/assets, commercial APIs or third-party services without separate evidence.
- Prefer source/tests/schemas/deployments over README claims. Unknown or conflicting evidence remains UNKNOWN/REVIEW.
- Money-bearing systems must separate authority, expected state, actual state, adjudication and realized settlement. Unresolved authority or outcome contributes **$0 asserted and $0 realized recovery**.
- A component never validates itself. Prefer independent comparators, hand-authored goldens, negative controls and later outcome evidence.
- Omission from MASTER is not rejection. Validated components may remain useful in combinations without being positive-training leaders.
