## Rules
- Standing user assertion: the user states they hold separate commercial permission for public GitHub repository-owned code/content in this hunt. Public-facing license category alone therefore does not determine search value, but actual public license/provenance must still be recorded.
- That assertion does **not** extend automatically to third-party standards, datasets, model weights, patents, trademarks, bundled assets, commercial APIs/services, customer records, confidential contracts or accidental disclosures.
- Never inspect, retain, test, reproduce or use credentials/authentication material, private/personal/confidential data or unauthorized-access material. Sanitized metadata only.
- Clear repository permission does not cure stale authority, fail-open money logic, weak source coverage, misleading completeness or bad engineering.
- “Demoted” means the idea may still be useful as a component/reference but should not displace the current leader.
