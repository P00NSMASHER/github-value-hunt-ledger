# RETALLY R4 — deterministic production-quality engineering candidate

R4 adds fully deterministic, reference-scoped synthetic stress workloads,
integer-cent randomized financial invariants and a private, aggregate-only
evidence-quality dashboard. The dashboard escapes output, never displays buyer
invoice identifiers, and is marked noindex/nofollow. It does not publish or
deploy itself.

## Testing

- 500 seeded randomized invoices verify exact signed money conservation.
- 273-invoice distribution replay checks row conservation and ordering.
- Dedicated CI benchmarks 10,000 and 100,000 synthetic invoices, two input
  orderings each. Wall time is reported; only deterministic integrity is
  considered an unconditional correctness gate.
- R1 financial ledger, R2 original document, R3 blind metrics, existing Phase 3
  synthetic gold and repository CI rerun.
- False release assertions, impossible counts and premature customer-proof
  claims fail closed. The separate freight pilot acceptance gate remains a
  mandatory release hold even if other supplied booleans are set.

This candidate does not certify commercial rights, actual 110-case freight
precision, independent payment clearing, independent human approval,
generalized production OCR, a security audit, or a real customer pilot.
Do not merge/enable customer deployments without independent review.
