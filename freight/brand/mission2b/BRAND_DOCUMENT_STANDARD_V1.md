# RETALLY | Production document standards v1
This supplements, and does not supersede, `freight/brand/RETALLY_BRAND_STANDARDS_V4.md`.

## Corporate system
- Exact approved glossy charcoal RETALLY wordmark with emerald arrow-shaped A for primary document header.
- Exact approved folded R icon separately only, never horizontally adjacent as a second logo.
- Ink `#0E1E29`, forest `#06392F`, emerald `#05B873`, mist `#EFF5F2`, ledger gray `#576D71`, action green `#087A50`; white canvas.
- Website stays on approved Hanken Grotesk / Instrument Serif usage. For portable editable customer documents use a consistent office-safe sans such as Carlito; no attempted recreation of logo text.
- US Letter; horizontal margins around 0.72 in; report headers/footers, page reference and print-safe clear space.
- Narrative text 9.5 to 11 pt; tables 8 to 9 pt when densely populated; financial values right-aligned; footers 7+ pt.
- Use meaningful table headings and alternate quiet backgrounds. Black-and-white print must distinguish states by text.
- Financial references: candidate, supported, customer-authorized, carrier-approved, posted, reversed, fee-eligible. These are not synonyms.
- Every live amount requires ID-level supporting entries and a reproducible calculation. Do not invent client findings or explanations for unknown exclusions.
- Every public financial illustration says SAMPLE; all internal drafts state approval status in header/footer.
- Prior to release visually inspect each rendered page, check editable source/PDF parity, grayscale, links and contact route. Document any unresolved issue explicitly.

## Release classification
- SAMPLE: safe educational claims only, not operational/customer proof.
- REVIEW DRAFT: legal/identity/data controls not finalized.
- INTERNAL: process standards or editing templates; not a customer deliverable.
- APPROVED: only after documented business, legal and security sign-off.
