# Hunter 03 — Freight, logistics & transportation

## Mission
Search public GitHub broadly for obscure, undernoticed, rare, unusually valuable, and monetizable public software, datasets, algorithms, workflows, schemas, standards, research code, or technical/business infrastructure relevant to **Freight, logistics & transportation**.

## Catalog rule
Record every meaningful candidate inspected in this file. For strong candidates, include detailed evidence. For weak/rejected candidates, record a concise reason so future runs do not repeat the work.

## Rights and safety
- Publicly visible is not automatically public domain.
- Respect repository/data licenses and copyright.
- No-license code is inspect/learn/clean-room only unless permission is established.
- Do not collect, reproduce, preserve, or exploit credentials, private/personal data, authentication material, accidentally exposed confidential information, or leaked trade secrets.
- Do not exploit vulnerabilities or unauthorized access paths.

- Exact commit / revision: `a43eedea03add0728eadfc1f8ea35cc3ca6867cc`
- Date inspected: 2026-09-19
- Status: strong
- What it contains: An Apache-2.0 freight-forwarding tariff and quote engine implemented primarily in PostgreSQL. `freight_tariffs` versions carrier/mode/service/origin/destination/currency with effective dates and rate source; `freight_tariff_rates` models weight bands, minimum charges, buy/sell rates, disbursements and bases including per-kg, per-CBM, W/M, container, shipment, document, piece and percent-of-value. It encodes the awkward freight arithmetic that generic pricing engines usually miss: dimensional weight, W/M, minimums, break boundaries, expiring tariffs, disbursements and buy/sell economics.

- Likely buyer / user: Freight forwarders, 3PLs, freight-audit firms and shippers with negotiated carrier rate sheets.
- Build-time or data advantage: Roughly 2–4 months of freight-domain schema, invariant and deterministic rating work saved; more importantly, it gives a tested canonical target for a clean-room PDF/XLS rate-card parser.
- Concrete evidence inspected: `supabase/setup/schema/verticals/freight_quoting.sql`; `supabase/setup/tests/freight.test.sql`; actual root `LICENSE`. Tests cover 5000/6000 volumetric divisors, W/M, derived carton volume, validity, non-overlapping bands, 44/45kg break boundaries, automatic tariff pricing, fuel by chargeable weight, minimum charge, disbursements and margin with explicitly invented test rates.
- License / rights: Apache License 2.0 verified from the repository LICENSE, including commercial copyright and patent grants. Test rates are explicitly synthetic/invented; the module states it ships no commercial carrier rates.
