### Kentucky-ai/opentakeoff
- URL: https://github.com/Kentucky-ai/opentakeoff
- Exact commit / revision: `6ff9cc355e60d6312c0c82e2ddac56cb212cc394`
- Date inspected: 2026-09-19
- Status: strong
- What it contains: Functioning construction takeoff engine with a browser canvas and packaged MCP server sharing measurement/quantity logic. It supports calibrated PDF/image plan sets, count/linear/area measurements, symbol workflows, markups/exports, roll-goods calculations, schedule/sheet-graph extraction, material quantities, human/agent review states and detailed per-shape provenance. The project explicitly gates a currently under-revalidation one-click room-detection feature instead of presenting it as production-proven.
- Rare or undernoticed value: A construction-specific measurement substrate that an AI agent can drive programmatically while retaining scale, geometry, production method, authorship, review state and original-vs-corrected boundaries. That provenance is unusually well aligned with auditable estimating and ScopeSignal evidence rather than generic vision demos.
- Monetization path: Construction takeoff copilot; per-project/per-seat estimating product; evidence-backed quantity-delta module for ScopeSignal; specialty-trade bid acceleration; review/QA layer for agent-generated takeoffs.
- Likely buyer / user: Specialty subcontractors, estimators, preconstruction teams, GCs, quantity surveyors and change-management teams.
- Build-time or data advantage: High. Reuses months of plan rendering, calibration, geometry, quantity math, exports, human review and agent-tooling work. The built-in provenance and benchmark machinery also reduces the cost of making AI-assisted quantities defensible.
- Concrete evidence inspected: `README.md`; `FEATURES.md` mapping capabilities to code; `web/test/variants.test.ts` exercising quantity/material-family inheritance edge cases; exact latest commit; repository LICENSE. README describes public plan-set/blind workflow benchmarks, review/export round trips, CI and a 53-tool MCP surface; FEATURES maps accuracy benches and tests to concrete source paths.
- License / rights: Apache-2.0 license verified at the inspected revision. Third-party plan/sample-data rights and dependencies should still receive normal product review before redistribution.
- Reuse classification: Directly reusable under Apache-2.0 terms for repository code.
- Why it is not already obvious / crowded: The value is not merely “open-source takeoff”; the non-obvious asset is the shared human/agent measurement contract with provenance and review, which fits evidence-first construction products exceptionally well.
- Combination opportunities: ScopeSignal contract-evidence gate + CAD/drawing-revision detection + IFC QTO + OpenTakeoff 2D quantity evidence + P6 schedule deltas can create a drawing-to-quantity-to-commercial-change packet.
- Next action: Benchmark one old/new plan revision pair through OpenTakeoff, preserving calibration/provenance, and measure whether the resulting quantity deltas are stable enough for a human-reviewed ScopeSignal change packet.
