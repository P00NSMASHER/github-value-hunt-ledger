# Hunter 09 — Legal, compliance & public-record workflows

## Mission
Search public GitHub broadly for obscure, undernoticed, rare, unusually valuable, and monetizable public software, datasets, algorithms, workflows, schemas, standards, research code, or technical/business infrastructure relevant to **Legal, compliance & public-record workflows**.

## Catalog rule
Record every meaningful candidate inspected in this file. For strong candidates, include detailed evidence. For weak/rejected candidates, record a concise reason so future runs do not repeat the work.

## Rights and safety
- Publicly visible is not automatically public domain.
- Respect repository/data licenses and copyright.
- No-license code is inspect/learn/clean-room only unless permission is established.
- Do not collect, reproduce, preserve, or exploit credentials, private/personal data, authentication material, accidentally exposed confidential information, or leaked trade secrets.
- Do not exploit vulnerabilities or unauthorized access paths.
