### agritheory/inventory_tools
- URL: https://github.com/agritheory/inventory_tools
- Exact commit / revision: `dd1e07d98eb81b2388acb922ce9ae3397a5af7ac`
- Date inspected: 2026-09-19
- Status: strong
- What it contains: A maintained Frappe/ERPNext inventory extension with a working Warehouse Location Optimization report. It computes item heat from movement history, resolves plan scope, ranks SKUs by movement count/quantity, orders candidate bins by walk distance from a warehouse-plan pickup point, tests item/slot fit and capacity from dimensions, suggests hotter-item placement, and can directly create/update putaway rules or set default warehouses from the resulting recommendations.
- Rare or undernoticed value: This is operational slotting logic integrated into an actual inventory stack, not a notebook. The optimizer bridges historical movement, physical warehouse geometry/capacity and executable putaway rules.
- Monetization path: Warehouse-slotting optimization service/app for ERPNext users; paid re-slotting studies; labor/travel-distance reduction product for distributors and light manufacturing warehouses.
- Likely buyer / user: ERPNext warehouses, distributors, manufacturers, 3PL warehouses and implementation partners.
- Painful problem: Picker/replenishment travel and poor slot placement consume recurring labor while most SMB warehouses lack dedicated slotting software.
- Build-time or data advantage: Roughly 2–4 months saved for an ERP-integrated slotting MVP because core report logic, capacity checks, walk-distance ordering and write-back workflow already exist.
- Concrete evidence inspected: `inventory_tools/inventory_tools/report/warehouse_location_optimization/warehouse_location_optimization.py`; docs for Warehouse Plan behavior; `inventory_tools/tests/test_warehouse_location_optimization.py` including cursor/no-fit behavior; latest semantic-release commit.
- License / rights: `license.txt` states MIT.
- Reuse classification: Directly reusable subject to MIT terms and Frappe/ERPNext dependency licenses.
- Why it is not already obvious / crowded: Value is hidden in a niche ERPNext extension rather than marketed as standalone slotting software; code search exposed the report implementation.
- Combination opportunities: Pair with warehouse operational data ingestion and an ROI calculator that translates reduced walk distance into labor dollars; could also combine with freight/dock scheduling to create a broader warehouse efficiency product.
- Scores: technical 9/10; commercial 8/10; rarity 8/10; completeness 9/10; build-time saved 9/10; data advantage 6/10; high-ticket potential 8/10.
- Next action: Benchmark on a synthetic warehouse plan plus SKU movement history, quantify travel-distance reduction versus current slotting, and determine whether the optimizer can run as a standalone advisory layer outside ERPNext.
