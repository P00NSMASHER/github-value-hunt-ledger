## Mission
Search public GitHub broadly for obscure, undernoticed, rare, unusually valuable, and monetizable public software, datasets, algorithms, workflows, schemas, standards, research code, or technical/business infrastructure relevant to **Scientific software & computational research**.

## Catalog rule
Record every meaningful candidate inspected in this file. For strong candidates, include detailed evidence. For weak/rejected candidates, record a concise reason so future runs do not repeat the work.

## Rights and safety
- Publicly visible is not automatically public domain.
- Respect repository/data licenses and copyright.
- No-license code is inspect/learn/clean-room only unless permission is established.
- Do not collect, reproduce, preserve, or exploit credentials, private/personal data, authentication material, accidentally exposed confidential information, or leaked trade secrets.
- Do not exploit vulnerabilities or unauthorized access paths.

- Why it is not already obvious / crowded: Provenance tooling is usually marketed to data/ML engineering, while this repository is oriented to scientific workflows and heterogeneous execution; the commercial compliance/reproducibility wedge is stronger than its modest star count suggests.
- Combination opportunities: Pair with `sciencecorp/galago-tools` + a lab scheduler to record instrument commands, workflow state and computational analysis in one evidence graph.
