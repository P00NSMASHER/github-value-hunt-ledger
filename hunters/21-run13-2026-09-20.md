### Concrete capability
This is not a generic script collection. The README states the EPP repository is installed into a designated conda environment on a host running Illumina Clarity LIMS and its scripts are invoked by the LIMS. Source inspection confirmed a broad installed-base sequencing handoff estate.

Most importantly, `scripts/illumina_run_parameter_parser.py` directly combines `genologics` Clarity entities with official Illumina InterOp Python bindings. It resolves a flowcell ID from Clarity process state for NextSeq, MiSeq, NovaSeq 6000, NovaSeq X Plus and MiSeq i100; maps that identity to a run directory; rejects zero or multiple matches; requires the run-parameter XML; attaches run XML artifacts back into Clarity; parses InterOp metrics; and writes operational run metrics back to Clarity output-artifact UDFs. Metrics include density, error rate, first-cycle intensity, percent aligned, Q30, PF, phasing/prephasing, PF reads and yield.

`scripts/samplesheet_generator.py` independently implements Clarity-driven Illumina run-input generation with NovaSeq X Plus / MiSeq / NextSeq handling, multiple index families, index reversal rules, project/run/flowcell metadata and index-distance checks. `scripts/generate_aviti_run_manifest.py` extends the installed-base handoff to Element AVITI with lane rules, sample linkage, PhiX consistency, index-family handling, reverse-complement behavior and collision checks. Other scripts cover ONT/MinKNOW, demultiplexing artifacts, sequencing running notes and related laboratory operations.

- `scripts/illumina_run_parameter_parser.py`: Clarity run identity -> filesystem run directory -> RunParameters/RunInfo -> InterOp metrics -> Clarity UDF writeback; explicit zero/multiple/missing/error exits.
