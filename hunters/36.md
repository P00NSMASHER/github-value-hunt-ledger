## Mission
Search public GitHub broadly for obscure, undernoticed, rare, unusually valuable, and monetizable public software, datasets, algorithms, workflows, schemas, standards, research code, or technical/business infrastructure relevant to **Procurement, vendor & spend management**.

## Catalog rule
Record every meaningful candidate inspected in this file. For strong candidates, include detailed evidence. For weak/rejected candidates, record a concise reason so future runs do not repeat the work.

- Publicly visible is not automatically public domain.
- Respect repository/data licenses and copyright.
- No-license code is inspect/learn/clean-room only unless permission is established.
- Do not collect, reproduce, preserve, or exploit credentials, private/personal data, authentication material, accidentally exposed confidential information, or leaked trade secrets.
- Do not exploit vulnerabilities or unauthorized access paths.

### plainfreight-com/china-usa-freight-price-index
- URL: https://github.com/plainfreight-com/china-usa-freight-price-index
- Exact commit / revision: `e54445f76abedb29d77acdb86afefa8780498318`
- Date inspected: 2026-09-19
- Status: watch
- What it contains: A deliberately published, dated China-to-USA freight price dataset generated from the publisher's own live customer rate card. The repository contains a dated price index from 0.5 kg through 1,000 kg plus chargeable-weight examples comparing actual/carton volume and multiple volumetric divisors. Old dated files are intended to remain so changes can be observed over time.
- Rare or undernoticed value: Unlike scraped marketing ranges, the publisher explicitly licenses the dataset and states that each figure comes from the rate card used for its own customer quotes. That creates a lawful real-price benchmark for anomaly/prioritization tests and dimensional-weight sanity checks.
- Monetization path: Use as an external market-reference feature in freight spend diagnostics, lane-pricing intelligence and benchmark demos; never treat it as contractual proof of overcharge for another carrier.
- Likely buyer / user: Small importers, freight procurement teams, consultants, freight-audit/payment vendors and forwarders benchmarking China-US shipments.
- Likely first paid wedge: Add an attributed “market context” section to a freight diagnostic so customers can see contract recovery separately from lawful external price context.
- Build-time or data advantage: Saves the effort of sourcing and rights-clearing a first real freight price series; useful especially because dated snapshots can support drift analysis.
- Concrete evidence inspected: actual `LICENSE`, `README.md`, data directory contents and exact latest commit. The repository includes CSV/JSON price-index files and a chargeable-weight CSV rather than README-only claims.
- License / rights: The repository's actual LICENSE explicitly applies CC BY 4.0 to the data and permits commercial sharing/adaptation with attribution and change indication; publisher identifies itself as Fisto LLC / Plain Freight.
- Reuse classification: Data reusable under CC BY 4.0 with required attribution; use class in the recovery product should remain `PRIORITIZATION_ONLY` / market context unless a customer's contract explicitly references the same pricing source.
- Why it is not already obvious / crowded: Zero stars and only a few kilobytes; value lies in rights-cleared real pricing provenance, not software volume.
- Combination opportunities: Feed it into the v6 external-truth layer alongside EIA/USDA, while Qatoto/Kareya remain the contractual rate authority. Pair the chargeable-weight examples with Freight-Vol-Calculator for dimensional sanity benchmarks.
- Value score: A 3/5, B 3/5, C 3/5, D 5/5, E 4/5, F 5/5 = **23/30**.
- Next action: Add an attributed external-market-reference adapter and benchmark that a contract-matching invoice still PASSes even when this market series is lower.
