- Status: strong
- What it contains: Zero-star Apache-2.0 local relationship-based authorization runtime specifically for AI-agent/tool actions. Current code implements memory-backed policy lifecycle, snapshot-pinned `Check`/`BatchCheck`, ALLOW/DENY/REQUIRE_APPROVAL decisions, caller authorization, redacted privileged `Explain`, typed verifier ports and deny/reject-by-default failure behavior.

- Monetization path: Use as the authorization/gating layer inside regulated workflow automation: policies decide whether an RPA/agent action may run, must stop for human approval, or is denied. Sell the vertical automation and governance outcome rather than the policy engine alone.
- Likely buyer / user: Regulated operations teams, agent/RPA platform vendors, compliance automation, MSPs, enterprises deploying tool-using AI agents.
- Build-time or data advantage: Estimated 1–3 months saved on relationship/action authorization semantics, approval-state binding, deny-safe behavior, snapshot consistency, caller scoping and conformance tests.
- Concrete evidence inspected: Exact signed latest commit; README explicitly distinguishes current pre-V1 implementation from planned transport/storage and states fail-closed defaults; recursive tree shows substantial actual code and tests including ~35 KB `api_test.go`, ~23 KB core regression tests, ~9.7 KB approval-binding tests, authorization/data/caller/cost modules and separate authorization/verifier conformance suites.
- License / rights: Apache-2.0.
- Reuse classification: Directly reusable subject to Apache-2.0.
- Why it is not already obvious / crowded: Zero stars and a new 2026 repository. The repo name sounds generic, while the actual niche is policy enforcement for consequential AI/tool actions.
- Combination opportunities: Put Cadrena in front of PETP/browser/API automations so high-risk actions become `REQUIRE_APPROVAL`; pair with Evidentia/ComplyBeacon to retain evidence of policy decisions. It can also gate KubeSqueeze or recovery operations before destructive/production-impacting actions.
