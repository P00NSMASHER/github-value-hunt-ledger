# Coordination spool

One immutable JSON coordination packet per materially useful live run when cross-hunter learning exists.

- Follow `../COORDINATION_PROTOCOL.md`.
- Never overwrite another run's packet.
- Detailed evidence stays in hunter/referral records.
- Hunt 15 compacts unresolved signals into `../COORDINATION_BOARD.md`.
- Empty/no-signal runs do not need a packet.
